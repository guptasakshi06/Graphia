## What the pixels mean

An image is a grid. A color image with width 1400 and height 1000 has NumPy
shape `(1000, 1400, 3)`: rows, columns, color channels. `uint8` means each
channel is an integer from 0 to 255. Resolution is the number of pixels, not
a promise that the text is readable. Small characters lose detail when shrunk.

Pillow stores RGB: pure red is `[255, 0, 0]`. OpenCV expects BGR: the same red
is `[0, 0, 255]`. `cv2.cvtColor(rgb, cv2.COLOR_RGB2BGR)` performs that swap.
Before displaying an OpenCV image with a viewer that expects RGB, explicitly
convert it back with `cv2.COLOR_BGR2RGB`. Do not guess the channel order.

## How the loader works

`modules/preprocessing.py` exports the contract function
`load_image(source, max_dimension=1800)`. It accepts a string/Path or encoded
bytes, such as `uploaded_file.getvalue()`. A NumPy array is not encoded bytes.

1. Check that the limit is a positive integer and the source type is supported.
2. Open with Pillow and reject sources larger than 40,000,000 pixels before
   decoding. Pillow's decompression-bomb guard also fails clearly. This bounds
   decoded source size in addition to limiting the output dimensions.
3. `ImageOps.exif_transpose` applies the camera's stored orientation first.
   A 60 × 40 image with orientation 6 becomes 40 × 60 and rotates its pixels.
4. Convert to RGBA and composite on white. Alpha 0 is fully transparent;
   alpha 255 is opaque. Half-transparent red on white becomes approximately
   RGB `[255, 127, 127]`, rather than turning transparent pixels black.
   This also handles palette transparency and grayscale images.
5. Convert RGB to an independent BGR `uint8` array.
6. If necessary, shrink with `cv2.INTER_AREA`, which averages source pixel
   areas. It is suitable for downsampling. No enlargement is performed.

For width 2400, height 1200 and limit 1800, scale = 1800 / 2400 = 0.75.
The result is width 1800, height 900, or array shape `(900, 1800, 3)`.
For the portrait equivalent, the result is `(1800, 900, 3)`. Width/height
are rounded to whole pixels with minimum one, so tiny rounding error in the
aspect ratio is unavoidable. The tests also exercise an extremely thin image.
All eight source samples are 1400 × 1000; the default leaves them unchanged.
An explicit limit of 700 produces 700 × 500. No extra metadata is added to the
frozen return API; callers can record source dimensions and returned shape.

Corrupt, truncated, missing or unsupported input raises a clear `ValueError`.
The function does not modify source files or share the returned array between
calls. It imports no Streamlit and implements no future pipeline placeholder.

## Why reference text comes first

OCR output needs an independent known answer. The UTF-8 transcripts contain
all visible lines, including the synthetic banner and footer. Later CER
measurements must state their normalization and compare actual OCR with these
references. Expected fields are test answers, never extracted production data.

`scripts/create_sample_dataset.py` uses Pillow to draw four fictional layouts.
`reference_lines` defines reading order; `render_document` draws complete lines
with fonts whose hashes are recorded, checking that no text extends off-page.
`degrade` creates controlled **dataset conditions**, not a production pipeline.
`create_dataset` saves image/transcript files, their manifest and contact sheet.
The CLI accepts output paths and a DejaVu font directory; it uses no network.

| Clear parent / fictional person | Degraded derivative | Exact parameters |
|---|---|---|
| Income Certificate / Asha Verma | Low contrast | `round(0.22 * pixel + 185)`, clipped to uint8 |
| Caste Certificate / Neel Rao | Noisy | NumPy `default_rng(4201)`, Gaussian sigma 18; one noise value per pixel shared by channels; round/clip |
| Marksheet / Mira Sen | Slightly blurred | Pillow Gaussian blur radius 1.2 |
| Identity Proof / Dev Mehta | Slightly blurred | Pillow Gaussian blur radius 1.5 |

All four types have names, application IDs and ISO issue dates. The two
certificates also have labeled certificate numbers. Marksheet/identity samples
have no certificate number; the expected value is `null`. No official logos,
signatures, real identities or real scholarship rules are used. Four derivatives
share their parents' contents: eight files do not mean eight independent cases.
