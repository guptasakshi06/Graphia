## What the operations mean

A threshold changes gray intensities into black (0) and white (255). For global cutoff T=127, `[90,127,128,180]` becomes `[0,0,255,255]`: only values strictly greater than T become white. A faint document can have every pixel above 127, so that cutoff can erase all its text.

Otsu tries global cutoffs and minimizes weighted within-class intensity variance, equivalently maximizing between-class variance. For groups at 40 and 200, it selects 40 in our simple test and separates them into black/white. It assumes useful intensity grouping; it does not understand characters. A uniform page has no two meaningful groups. Its selected cutoff is reported, not hidden.

Adaptive thresholding uses a local Gaussian-weighted mean minus C. Our settings are block size 31 (a 31x31 neighborhood) and C=11. A pixel above this local cutoff becomes white. The block must be odd and greater than 1 so it has a center. Local cutoffs can cope with lighting differences, but noise also changes local decisions. The uneven-light test is a small artificial gradient and dark line, not a newly claimed dataset condition.

A structuring element is a small shape moved across the image. We use a rectangle of ones. OpenCV morphology treats high/white values as foreground, so the helper first computes `255 - image`: dark text becomes white foreground. It restores polarity with the same subtraction after the operation.

- Erosion retains white foreground only where the kernel fits: it thins text. A centered 5x5 foreground square with a 3x3 kernel becomes 3x3.
- Dilation expands white foreground: that 5x5 square becomes 7x7.
- Opening is erosion then dilation. It can remove isolated foreground specks, but can also erase a thin letter stroke permanently.
- Closing is dilation then erosion. It can fill a small hole/gap, but may join characters.

Kernel size 1 leaves pixels unchanged. The contract allows even morphology sizes; the default size is 2 with anchor `(1,1)`. It is asymmetric and can shift strokes. Size 3 is used for the easy centered-square numerical tests, while the saved dataset comparisons use size 2. Borders use OpenCV's constant neutral values on the inverted foreground (255 for erosion, 0 for dilation), avoiding artificial edges. Grayscale morphology uses min/max without secretly adding a threshold. These functions assume the documented dark-text/light-background input convention; they do not guess or correct reversed scans.

## Complete executable files and key functions

`modules/preprocessing.py` preserves the SG01 loader and SG02 helpers and adds:

- `threshold_image(gray, method="otsu", global_threshold=127, adaptive_block_size=31, adaptive_c=11)` returns `(uint8_image, selected_otsu_threshold)`. The cutoff is a float for Otsu, otherwise `None`. `none` returns a copy. All settings are validated, even for an inactive method.
- `apply_morphology(gray, method="none", kernel_size=2)` applies one chosen operation with explicit foreground inversion and returns a fresh array. It accepts binary or grayscale uint8.
- `run_pipeline(image_bgr, options=None)` implements contract v1. It returns exactly `stages`, `ocr_input`, and `parameters`. Stages are `original` (BGR), `grayscale`, `denoised`, `enhanced`, `thresholded`, `morphology` (all 2D gray/binary). Every stage and `ocr_input` has separate storage, including bypasses. The caller's image/options are preserved. No UI import is needed.

The nine public options retain these contract defaults:

| Key | Default | Allowed values |
|---|---|---|
| denoise | median | none, gaussian, median |
| kernel_size | 3 | positive odd integer |
| contrast | clahe | none, equalize, clahe |
| threshold | otsu | none, global, otsu, adaptive |
| global_threshold | 127 | integer 0–255 |
| adaptive_block_size | 31 | odd integer >1 |
| adaptive_c | 11 | finite number, including negative values |
| morphology | none | none, erosion, dilation, opening, closing |
| morph_kernel_size | 2 | positive integer, including even sizes |

Unknown keys and invalid values raise `ValueError`. Booleans are rejected as numerical settings. Supported NumPy numeric scalars are converted to ordinary int/float so resolved parameters serialize with `json.dumps(..., allow_nan=False)`. Parameters also record Otsu's actual cutoff, CLAHE clip limit 2.0 / grid 8x8, Gaussian adaptive method, morphology geometry/polarity and input/output shapes. CLAHE grid denotes tile counts, not pixel sizes. All default settings are initial candidates, not evidence of best OCR accuracy. No contract change is requested.

`run_pipeline` chains only the selected stages. `none` keeps the preceding image as an independent copy. Its default path is gray → median 3x3 → CLAHE 2.0/8x8 → Otsu → morphology bypass. A complete bypass call can use `{"denoise":"none","contrast":"none","threshold":"none","morphology":"none"}`.

`scripts/run_experiments.py` retains the SG02 six-method runner. `--sprint SG03` selects the new fixed comparison set; output defaults to `outputs/experiments/SG03`. `compare_sg03` creates three thresholds from the same unenhanced grayscale, four independent morphology alternatives from that Otsu result, and one separate default pipeline. This distinguishes method demonstrations from the selected pipeline. It does not chain erosion/dilation/opening/closing. Fixed SG03 settings avoid an exhaustive parameter search; SG02-specific tuning flags reject nondefault values in SG03 mode.

`save_sg03_comparison` renders labeled full pages and common crops with a fixed 0–255 display scale. `run_sg03_experiments` verifies source hashes, writes outputs/settings/measurements, and saves every default stage. It reads only the manifest's fictional dataset; it is not an upload persistence mechanism.
